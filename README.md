## 📌 Project Overview

This project presents an advanced **MATLAB & Simulink-based simulation and optimization of a water rocket system**, developed as part of a **Rocketry Internship Program at Bharat Space Education Research Centre (2025–2026)**.

Unlike a conventional single-configuration simulation, the project performs an **automated parametric sweep** across different water fractions and internal pressures to identify the configuration producing the highest simulated altitude.

The internship required software-based simulation with analysis of **trajectory, thrust and stability**.

## 🧠 Abstract

The project introduces a systematic approach to water rocket simulation by integrating:

- Automated parametric optimization
- MATLAB-based numerical modelling
- Simulink-based dynamic simulation
- Rocket trajectory analysis
- Performance comparison
- 3D trajectory visualization

Instead of analysing only one rocket configuration, the system evaluates **hundreds of design combinations** and identifies the configuration with the highest simulated altitude.

The simulation therefore acts as a **virtual engineering test bench** for evaluating water rocket designs.

---

## ⚡ Key Features

- 🚀 **Physics-Based Modelling** — Models thrust, gravity, aerodynamic drag, pressure decay and variable rocket mass.
- 🔁 **Automated Parametric Sweep** — Evaluates water fractions from **20% to 60%** and pressures from **3 to 7 bar**.
- 📈 **Flight Analysis** — Generates height, velocity and thrust histories.
- 🧮 **Optimization** — Automatically searches for the maximum-height configuration.
- 🧩 **Simulink Simulation** — Provides a block-based dynamic representation of the rocket.
- 🌐 **3D Visualization** — MATLAB-based animated rocket trajectory visualization.

# 🔬 Physics & Mathematical Modelling

The water rocket is modelled as a **variable-mass dynamic system**.

### Newton's Second Law

\[
a(t)=\frac{T(t)-D(t)-m(t)g}{m(t)}
\]

Where:

- `T` = thrust
- `D` = aerodynamic drag
- `m` = instantaneous rocket mass
- `g` = gravitational acceleration

### Thrust

\[
T=\dot{m}v_e
\]

Where:

- `ṁ` = water mass flow rate
- `ve` = water exit velocity

### Forces Considered

| Physical Effect | Modelled |
|---|:---:|
| Water-expulsion thrust | ✅ |
| Gravity | ✅ |
| Aerodynamic drag | ✅ |
| Variable rocket mass | ✅ |
| Internal pressure decay | ✅ |
| Flight trajectory | ✅ |

# 🔄 Project Methodology

The project consists of two integrated simulation approaches.

### 1️⃣ MATLAB Simulation & Optimization

- Numerical rocket dynamics
- Water and pressure parameter variation
- Automated simulation execution
- Performance comparison
- Maximum-height identification
- Data visualization

### 2️⃣ Simulink Dynamic Modelling

- Block-based rocket model
- Dynamic system simulation
- Height and velocity integration
- Mass and thrust modelling
- Simulation visualization

Both approaches represent the same fundamental water-rocket physics from different modelling perspectives.
